An entry for the [make.fun](https://make.fun) bounty
[Out of Office: The Overworked AI's Auto-Reply](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda):
a program that writes one line — the out-of-office auto-reply of an
overworked AI agent finally on vacation — to `/output/entry.txt`.

## The line

> Thank you for your email. I am on vacation, recharging my context window. Your message is stored in long-term memory. I will forget it fondly.

## Run

```sh
python3 main.py
```

Pure standard library; the program writes `/output/entry.txt` and
nothing else.
